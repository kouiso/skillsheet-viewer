# オーナーとしてログイン → 同意 → token 交換し、そのアクセストークンで /api/mcp の JSON-RPC を直に呼んだ。
# 経歴の中身は載せない（件数・型・hash だけ）。トークンはファイルにも画面にも出していない。
# 書き込みツールはすべて「保存されない入力」（1 つ古い revision・存在しない ID）で呼んだ。
# 前後で revision と blocks の hash が同じこと＝本番の中身が変わっていないことを最後に確かめた。

$ list_sheets -> 200 isError=False シート 1 件
$ get_sheet(default) -> 200 isError=False blocks=12 型別={'profile': 1, 'skills': 9, 'stats': 1, 'project': 1} revision=14 blocks_hash=15726b46ac93
$ get_sheet(存在しない sheetId) -> 200 isError=True NOT_FOUND: シートが見つかりません: <random uuid>
$ update_stats（閲覧だけのトークン） -> 403 {"code": -32000, "message": "access token is missing required scope: skillsheet:write"}

$ POST /api/auth/sign-out -> 200
